A NOTE ON ACCURACY

Helpful signal. Not a guarantee.

This is an academic prototype trained on a labelled dataset. URL patterns can change, and a malicious site can use a URL that looks ordinary. The system does not inspect HTML, verify live website reputation, or block IoT traffic. Use independent security checks before trusting a link.
